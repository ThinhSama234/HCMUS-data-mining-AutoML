\chapter{Hướng dẫn tái lập và mã nguồn}
\label{ch:phuluc-repo}

Toàn bộ mã nguồn được công bố tại kho lưu trữ:
\begin{center}
\url{https://github.com/ThinhSama234/HCMUS-data-mining-AutoML}
\end{center}
Kho chứa tệp \texttt{README.md} hướng dẫn cài đặt môi trường (Python 3.9--3.11,
PostgreSQL và MinIO qua Docker Compose) và cách chạy hệ thống. Tóm tắt các bước:
\begin{enumerate}
    \item Tạo môi trường ảo và cài đặt phụ thuộc: \texttt{pip install -r requirements.txt}.
    \item Khởi động PostgreSQL và MinIO: \texttt{docker-compose up -d}, sau đó nạp
    danh mục bằng \texttt{python -m storage.seed}.
    \item Chạy giao diện: \texttt{streamlit run console/app.py}.
    \item Trên trang Methods, tích hợp thư viện (kéo ảnh Docker); trên trang
    Training, chọn bộ dữ liệu và ngân sách rồi khởi chạy; kết quả hiển thị ở trang
    Evaluation.
\end{enumerate}
